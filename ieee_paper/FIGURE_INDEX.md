# Figure and dataset index

All figure assets are genuine copies from the supplied handoff except (1) the six-view presentation plate, composed by scripts/compose_camera_plate.py from the six final Blender camera PNGs, and (2) the paper-specific near-expiry comparison, regenerated by scripts/generate_paper_figure_overrides.py from the copied donation_simulation.csv with concise axis labels and Monte Carlo intervals.

- Analytical figures: CIE 1931/sRGB gamut; chromaticity; delta E by condition; red delta E; red components; dominant wavelength/purity; confusion matrices; trigger-error sensitivity; near-expiry comparison; donation-capacity sensitivity; sustainability sensitivity.
- Architecture: methodology flowchart; component, sequence, data-flow, and deployment diagrams; UML class and object diagrams. PNGs are included, with source SVGs retained where present.
- Blender output: all twelve 960x640 controlled measurement renders and contact sheet; all six 2560x1440 presentation camera renders; scene-evidence cards.
- Application: six desktop page screenshots at 1440 pixels and one Overview mobile screenshot at 390 pixels.
- Numerical evidence: the original CSV result tree and copied configuration, CIE tables, CIEDE2000 verification cases, run metadata, Phase 4 test logs, and final IEEE build logs are under data/.

The figure captions in main.tex identify whether an image represents analytical computation, RGB visualization, software architecture, or application evidence.
